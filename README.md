# 語言學習小幫手（隨身版）

日文／韓文／英文旅遊／多益的自適應練習，**離線可用**。

**打開就用：** https://hajimeutaarashiyuki.github.io/language-lab/

## 放到手機主畫面

用 **Safari**（iPhone）或 Chrome（Android）開上面的網址 → 分享 →「加入主畫面」。
之後點圖示就能用，**不需要網路、也不用開電腦**。

## 說明

- **學習進度只存在你自己的手機上**，不會上傳到任何地方。
  換手機請用 App 裡的「備份進度」搬移。
- 這個頁面由 language-learning 專案自動產生（`tools/deploy_pages.py`），請勿直接編輯。
